**Penpot Import Guide**

Use esta pasta para montar o arquivo base no Penpot:

Arquivos em ordem:
1. `01-home.png`
2. `02-library.png`
3. `03-browse.png`
4. `04-series-detail.png`
5. `05-reader.png`
6. `06-novel-detail.png`
7. `07-downloads.png`
8. `08-settings.png`

**Montagem sugerida**

1. Abra o Penpot e crie um projeto novo.
2. Crie uma página chamada `Overview`.
3. Arraste os 8 PNGs desta pasta para o canvas.
4. Organize em 2 colunas, nesta ordem:
   - Coluna 1: `01-home`, `03-browse`, `05-reader`, `07-downloads`
   - Coluna 2: `02-library`, `04-series-detail`, `06-novel-detail`, `08-settings`
5. Use gap horizontal de `120` e gap vertical de `140`.
6. Deixe uma margem externa de cerca de `160` no canvas.
7. Fundo sugerido da página: `#111216`.

**Páginas individuais**

Depois do overview, crie estas páginas:
- `01 Home`
- `02 Library`
- `03 Browse`
- `04 Series Detail`
- `05 Reader`
- `06 Novel Detail`
- `07 Downloads`
- `08 Settings`

Em cada página:
1. Arraste o PNG correspondente.
2. Centralize com margem de `160`.
3. Desenhe por cima os ajustes que você quiser fazer.

**Recomendação**

Comece ajustando só estas 3 telas:
- `02 Library`
- `04 Series Detail`
- `05 Reader`

Elas definem quase toda a HUD do app.
