# Project Brief

## What Aethon Is
Aethon is a new product foundation built from the upstream Moku codebase.

## Upstream Base
- Base repository: Moku
- Purpose in Phase 0: establish a clean fork foundation without changing application behavior

## Current Mission
Create a stable product foundation first: repository setup, durable documentation, and clear phased guidance.

## Long-Term Direction
Aethon is manga-first in the near term, with room to explore other media formats later once the desktop foundation is stable.

## Non-Goals For Now
This phase does not include novel, EPUB, PDF, or Android implementation.
